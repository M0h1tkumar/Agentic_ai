# Closed vs Open Source vs Open Weight Models

## Closed Models

- Model weights and source code are not publicly available.
- Usually accessed through APIs.

**Examples:** GPT-4, Claude, Gemini

## Open Source Models

- Source code and model are publicly available.
- Anyone can study, modify, and deploy them.

**Examples:** OpenClaw, GPT-Neo

## Open Weight Models

- Model weights are available.
- Source code or training data may not be fully open.

**Examples:** Llama 3, Mistral

## Comparison

| Closed                | Open Source        | Open Weight            |
| --------------------- | ------------------ | ---------------------- |
| API access            | Fully open         | Weights available      |
| Limited customization | High customization | Moderate customization |
| Commercial control    | Community driven   | Mixed approach         |

## Conclusion

Closed models offer convenience, open-source models provide flexibility, and open-weight models balance accessibility with controlled development.
