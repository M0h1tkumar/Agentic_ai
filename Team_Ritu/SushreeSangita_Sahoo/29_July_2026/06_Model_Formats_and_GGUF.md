# Model Formats and GGUF

## Common AI Model Formats

- GGUF
- GGML
- PyTorch (.pt, .pth)
- SafeTensors (.safetensors)
- ONNX
- TensorFlow SavedModel
- TensorFlow Lite (TFLite)

## What is GGUF?

GGUF (GPT-Generated Unified Format) is a model format designed for running large language models efficiently on local computers.

### Advantages

- Faster loading
- Smaller storage size
- Easy to use with Ollama, Jan, and LM Studio
- Optimized for CPU inference

## Conclusion

Different model formats are designed for different AI frameworks. GGUF is one of the most popular formats for running LLMs locally with good performance.
