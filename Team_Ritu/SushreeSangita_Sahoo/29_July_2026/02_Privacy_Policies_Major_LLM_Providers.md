# Privacy Policies of Major LLM Providers

## OpenAI

- Collects user interactions to improve services.
- Users can control data usage in many products.
- Enterprise users receive stronger privacy protections.

## Google (Gemini)

- Stores user activity depending on account settings.
- Data may be used to improve AI services.
- Users can manage or delete activity through Google Account settings.

## Anthropic (Claude)

- Focuses on responsible and secure AI.
- User data may be used to improve models unless restricted.
- Enterprise customers receive enhanced privacy options.

## Comparison

| Provider  | Uses Data for Improvement | User Controls | Enterprise Privacy |
| --------- | ------------------------- | ------------- | ------------------ |
| OpenAI    | Yes                       | Yes           | Yes                |
| Google    | Yes                       | Yes           | Yes                |
| Anthropic | Yes                       | Yes           | Yes                |

## Conclusion

All major AI providers offer privacy controls, but users should always review settings before sharing sensitive information.
