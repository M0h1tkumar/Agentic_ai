# Multica & Slack Integration

To bring Multica agents directly to the users, we integrated the platform with Slack.

## Steps to Connect
1. **Create a Slack App:** Go to `api.slack.com` and create a new App from scratch.
2. **Bot Tokens:** Under `OAuth & Permissions`, add the following Bot Token Scopes:
   - `app_mentions:read`
   - `chat:write`
   - `channels:history`
3. **Install to Workspace:** Install the app into your Slack workspace and copy the `Bot User OAuth Token`.
4. **Multica Configuration:** In the Multica dashboard, navigate to Integrations -> Slack. Paste the Bot Token.
5. **Event Subscriptions:** In the Slack API dashboard, enable Events and provide the webhook URL generated by Multica (e.g., `https://your-multica.com/api/slack/events`). Subscribe to `app_mention`.

## Result
Users can now type `@AgentName What is the status of the project?` in a Slack channel, and the Multica agent will seamlessly reply in the thread!
