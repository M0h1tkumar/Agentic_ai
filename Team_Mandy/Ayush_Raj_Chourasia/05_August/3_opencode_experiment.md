# OpenCode Experiment

**OpenCode** is emerging as one of the best local agent runtimes available, especially when compared to running agents raw in the CLI.

## Key Advantages Over Standard CLI
1. **Deep IDE Context:** OpenCode understands the entire directory structure, open tabs, and Git state. When an agent runs in this runtime, it doesn't need to ask "what file am I looking at?" It already knows.
2. **Terminal Control:** OpenCode allows the agent to safely execute bash scripts, run tests, and scrape outputs dynamically, making it incredibly powerful for coding tasks.
3. **Multi-Agent Compatibility:** Multica can delegate specific developer tasks down to an OpenCode runtime sitting on a developer's machine, effectively creating a distributed workforce.

**Conclusion:** For software development tasks, OpenCode is superior to OpenClaw. OpenClaw should be reserved for general-purpose workflow orchestration.
